TRANSPARÊNCIA

Políticas e termos.

O que esta demonstração acadêmica faz e o que não faz.

1. Sobre o projeto

O BarberSync é um protótipo acadêmico para apresentação de interfaces de barbearias, clientes e proprietários.

2. Informações e privacidade

Este protótipo usa HTML, CSS e JavaScript simples. Cadastros e reservas são salvos no armazenamento local deste navegador. Não existe servidor, banco de dados compartilhado ou autenticação segura.

As senhas fictícias ficam armazenadas localmente sem criptografia. Não informe senhas verdadeiras nem dados pessoais.

3. Agendamentos e horários

O JavaScript bloqueia horários duplicados para a mesma barbearia e profissional apenas neste navegador. Não há reservas reais nem sincronização entre usuários e dispositivos.

4. Avaliações, fotos e produtos

Os comentários, nomes, preços e fotos são ilustrativos. Os produtos não podem ser comprados por esta versão.

5. Planos e pagamentos

Os planos exibidos são uma proposta para a disciplina. Não há cobrança ou assinatura.

6. Melhorias futuras

Para uso real seria necessário um servidor e banco de dados com autenticação segura e agendamentos sincronizados.
